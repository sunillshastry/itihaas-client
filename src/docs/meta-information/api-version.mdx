The version endpoint provides information about the currently deployed version of the Itihaas API.

##### Endpoint

<CodeBlock language="http">
	{`GET https://itihaas-api.onrender.com/api/version`}
</CodeBlock>

This can be useful when troubleshooting issues, checking which API version is currently deployed, or confirming that your application is communicating with the expected version. For version-specific information about available endpoints and response formats, please refer to the corresponding API Reference documentation.
