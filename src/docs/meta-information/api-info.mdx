The API info endpoint provides general information and metadata about the Itihaas API.

##### Endpoint

<CodeBlock>{`GET https://itihaas-api.onrender.com/api/info`}</CodeBlock>

The API root is also available at:

<CodeBlock>{`GET https://itihaas-api.onrender.com/`}</CodeBlock>

These endpoints can be used to quickly verify that the API is accessible and to view general information about the service without making a request to a specific data endpoint. The root endpoint is also useful as a simple starting point when exploring the API directly in a browser or API client.
